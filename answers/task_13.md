# Завдання 13. Правила команди для роботи з ШІ-асистентом (середнє)

Тема: ШІ в процесі: незалежність оцінки, тести, метрики, перевірка зміни (лекція 9).

## Умова

У журналі домовленостей команди, яка працює з ШІ-асистентом, записано чотири правила.

> 1. «Щоб заощадити час, Planning Poker починаємо з показу оцінки від асистента; команда голосує, відхиляючись від неї не більше ніж на один крок».
> 2. «Тести для функції нарахування штрафу асистент згенерував за готовим кодом функції. Усі проходять, покриття 100 %, тож критерії приймання вважаємо перевіреними».
> 3. «Ціль команди: приймати без змін щонайменше 80 % пропозицій асистента. Це доведе, що чернетки якісні».
> 4. «Агент створив зміну на 900 рядків у чотирьох модулях. Рецензентом призначено розробника, який доручив задачу агентові й прийняв результат; на перегляд відведено двадцять хвилин».

Для кожного правила: назвіть проблему, поясніть, яку обґрунтовану вимогу вона порушує, і запропонуйте виправлене правило.

Що має бути у відповіді: Чотири короткі відповіді (проблема, обґрунтування, виправлене правило).
